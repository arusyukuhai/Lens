# Replacer — 高速化版（単一走査・隠しメモリなし）

これは前回の単一走査版から、学習・推論の結果をできるだけ変えずに高速化した版です。`main.py` と `gpu_replace_persistent.py` は必ず同じディレクトリに配置してください。追加のGPU専用依存関係はありません。SciPyが入っていればRidgeのCholesky解法を高速化し、なければ従来のNumPy解法にフォールバックします。

## 変更した点

1. **推論GAの候補キャッシュ** — 一度計算した候補文字列と同じ文字列を、同一の内側GA実行中に再評価しません。推論の候補集合、評価スコア、選択や乱数系列はそのままです。 `infCache=...` は再評価を省けた候補数。`inference_evaluations` / `infEq` は実際に実行した回数を表示します。キャッシュは各外側世代の推論処理ごとに破棄します。
2. **MPS推論入力の高速再設定** — GPUへ転送する入力テンソルを `sample_count` の最大容量ではなく、実際の有効候補数のみにしました。すでに同じモデルをGPUにパック済みの推論GAでは、評価結果に関係しないアンカー用頻度表の再構築も省略します。外側の評価やGPUパック前には従来通り統計を更新します。
3. **CPU版の候補ルール除外** — 現在の状態に存在しない必須リテラル／連続2トークンが含まれるルールは、完全照合せずに飛ばします。状態が実際に変化したときだけインデックスを更新します。元の `replace_once_cpu` の呼び出し互換性は維持しています。
4. **Hall of Fameの厳密な早期打ち切り** — 現在の `--hof-min-distance` より近い個体にはなれないことが確定した時点で、残りのルール比較をスキップします。近似距離ではありません。近い個体の中から最も近いものを選ぶロジックは同じです。
5. **RidgeのSPD解法と固定ターゲット前処理** — SciPyが使える場合はCholeskyの三角解法を活用。各世代で不変なケース別の順位ペアは、ゲノムごとでなく一度だけ構築します。
6. **MPSの単一走査専用ルール発火記録** — 各ルールは1系列につき最大1回しか実行されないため、旧式のインクリメントから `1` の書き込みに簡略化しました。

通常の `-1` ワイルドカード、`-1..-111` の置換系、GA・Pareto・Spearman・推論精度の考え方は維持しています。`-2/-3` などの隠しメモリ用ワイルドカードや `-128..-151` の専用オペコードは復活させていません。

## 起動

```bash
python main.py --self-test
python test_fast.py
python main.py --backend mps --population 450 --rules 1500
```

MPSが使用できない場合は `--backend cpu` にしてください。チェックポイントと学習パラメータは前版と互換です。`--load` で継続できます。

## 計測と検証

同じCPU環境での関数単位の参考計測（実装前→実装後）：

- CPU置換評価（384ルール × 18系列 × 500トークン）：約0.135 → 0.044 秒（約3.1倍）
- HoFの距離評価（900保存個体 × 1500ルール）：約0.145 → 0.004 秒（約36.8倍）
- 内側推論GA（再現性テスト）：候補評価200 → 151件、同じスコア・選択結果
- ミニ学習（CPU、2世代、推論あり）：各世代のSpearman、推論、Pareto関連指標が変更前と一致。速度は第0世代0.0219→0.0173秒、第1世代0.0202→0.0152秒

これらは**個別条件下の計測**であり、実際の学習全体の速度向上率は系列の長さ、ルール数、GPU、推論の重複率、HoF数に依存します。この環境にMPS対応GPUがないため、Metalカーネルの実機コンパイルと実機速度測定は未実施です。
